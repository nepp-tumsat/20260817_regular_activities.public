# AI駆動開発ハンズオン ハンドアウト(2026-08-17 定例活動)

NePP の定例活動で、Claude Code を使ってチームで動くものを1つ作るハンズオンのハンドアウトです。当日の流れ・セットアップ手順・チーム開発でコンフリクトを避ける作法をまとめています。

**→ https://nepp-tumsat.github.io/20260817_regular_activities.public/**

参加者にはこの URL を案内してください。ローカルで見る場合は `open index.html` でそのまま開きます。

## このリポジトリについて

配布用のページだけを置く公開リポジトリです。運営側の資料(検証項目・予算・上限設定などを含む運営票)は非公開リポジトリ [`nepp-tumsat/20260817_regular_activities`](https://github.com/nepp-tumsat/20260817_regular_activities) にあります。**運営向けの内容をここに置かないでください。**

| ファイル | 内容 |
|---|---|
| `index.html` | 参加者ハンドアウト(印刷対応) |

## 更新するとき

`index.html` を編集して `main` に push すると、GitHub Pages に自動で反映されます(反映まで1分程度)。

非公開リポジトリ側にも同じ `index.html` のコピーが置いてあります(運営がオフラインで確認するため)。**編集したら両方に反映してください。**

イベントごとに使い回す場合は、冒頭の日付表記(`.kicker`)、`<title>`、「今日の流れ」のタイムテーブルを書き換えてください。
