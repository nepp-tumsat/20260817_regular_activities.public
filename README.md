# Claude Code セットアップ手順(参加者配布用)

NePP のハンズオンで、チームに配られた API キーを使って Claude Code を動かすまでの手順です。

**→ https://nepp-tumsat.github.io/20260817_regular_activities.public/**

参加者にはこの URL を案内してください。ローカルで見る場合は `open index.html` でそのまま開きます。

## このリポジトリについて

配布用のページだけを置く公開リポジトリです。運営側の資料(検証項目・予算・上限設定などを含む運営票)は非公開リポジトリ [`nepp-tumsat/20260817_regular_activities`](https://github.com/nepp-tumsat/20260817_regular_activities) にあります。**運営向けの内容をここに置かないでください。**

| ファイル | 内容 |
|---|---|
| `index.html` | 参加者向けセットアップ手順(印刷対応) |
| `assets/style.css` | スタイル |

## 更新するとき

`index.html` を編集して `main` に push すると、GitHub Pages に自動で反映されます(反映まで1分程度)。イベントごとに使い回す場合は、冒頭の日付表記(`.kicker`)と `<title>` を書き換えてください。
